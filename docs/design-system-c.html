design system · opção c

Terminal_

Grade de 1 px, contraste alto e um único verde ácido. O texto é sans para leitura; a mono fica reservada para labels, identificadores e números — o vocabulário de terminal sem o cansaço de ler prosa em código.

radius 2–4 px densidade máxima Inter + JetBrains Mono lima #B6F24A dark-first
quando escolher

Se o público é DevSecOps e a ferramenta deve parecer parte do pipeline: CLI, CI, editores. Reconhecível em um segundo, mas exige disciplina para não virar ruído.
