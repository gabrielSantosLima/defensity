Três direções para o app desktop.

Cada página é um design system completo e utilizável: tokens de cor, escala tipográfica, espaçamento, raios, componentes base, tabela de achados e uma tela de aplicação montada. As três usam o mesmo conteúdo para a comparação ser justa.

Atenção: cada página tem um alternador de tema no canto superior direito. Vale olhar as três em claro e em escuro antes de decidir — o tema padrão de cada uma é apenas uma preferência, não uma limitação.

Comparação

Critério A · Console B · Atelier C · Terminal
Personalidade Ferramenta séria, próxima de IDE e observabilidade Documento calmo, próximo de relatório e publicação Pipeline, próximo de CLI e editor
Densidade Alta — muitos dados por tela Média — respiro e leitura longa Máxima — grade de 1 px
Tipografia System sans + mono nos dados Serifa nos títulos, sans no corpo, mono nos dados Inter para texto, JetBrains Mono para dados
Sinal Azul #2563EB Verde #0F6B57 Lima #B6F24A
Forma Raio 4–8 px, borda fina Raio 6–18 px, pílulas Raio 2–4 px, cantos retos
Tema padrão Claro Claro Escuro
Ponto forte Escala para volume e triagem rápida Explica o achado; parece cuidado e não alarme Imediatamente reconhecível pelo público técnico
Risco Pode parecer genérica entre tantos dashboards Serifa em app pode soar “site”, não “ferramenta” Cansa e vira ruído com uso prolongado

Como decidir

  • Se a tela principal é triagem em tabela, a opção A vence.
  • Se a tela principal é o relatório explicado, a opção B vence.
  • Se a tela principal é o monitoramento contínuo feito por engenheiros, a opção C vence.
  • Também é possível escolher a base e importar um elemento de outra: por exemplo C com a tabela de A, ou A com a serifa de B só nos títulos de relatório.
