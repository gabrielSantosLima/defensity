Design system · opção A

Console

Uma interface de instrumento: cinzas frios, um único azul de sinal e densidade alta. Feita para ser lida em tabelas longas, com hierarquia construída por contraste de superfície, não por cor.

radius 4–8 px densidade alta sans + mono azul #2563EB claro/escuro
Quando escolher Se o produto deve parecer uma ferramenta de trabalho séria, próxima de um IDE ou de um console de observabilidade. Escala bem para muitos dados na tela.
